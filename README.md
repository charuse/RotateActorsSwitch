# RotateActorsSwitch
### Rotate LiveActors Via Linked Generator IDs
  
|Var|Desc|
|-----|-------|
|Obj_arg0|Rotate X|
|Obj_arg1|Rotate Y|
|Obj_arg2|Rotate Z|
|SW_A|Rotate on Enable|
  
*Value is added to current rotation value for all LiveActors with linked Generator IDs*  
*Rotates only once, triggered on SW_A enable*
